# M&M Goals Dashboard

Shared goals/habits/standards dashboard with real-time sync between Matthew & Marie via Firebase.

## Stack
- Plain HTML/CSS/JS (no build needed)
- Firebase Firestore for real-time sync
- Deploys to Vercel (free)
- PWA: add to phone home screen

## Setup
1. Firebase project: `goals-dashboard-ee34e`
2. Firestore database must be enabled in test mode
3. Vercel deploys from `main` branch automatically

## Phase 1 (current)
- Login (Matthew/Marie)
- Today tab with quick-log buttons
- Week view with habit grid
- Outcomes with % tracking
- Standards 1-5 ratings
- Weekly check-in form with archive
- Real-time sync between devices
